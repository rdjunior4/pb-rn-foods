## 1. VISÃO GERAL DO PROJETO

### O que é a PB&RN Foods?
Distribuidora B2B de alimentos e produtos de higiene/limpeza que atende **empresas** (CNPJ) no mercado atacarejista do **Nordeste Brasileiro**.

### Por que E-commerce?
- **Digitalização do canal de vendas** — reduzir dependência de vendedores externos
- **Escalabilidade** — atender mais clientes sem aumentar equipe proporcionalmente
- **Dados** — insights sobre comportamento de compra, sazonalidade, margem
- **Competitividade** — concorrentes já operam online (Cash, Assaí Atacadista, Atacadão)

## 8. PAGAMENTO ONLINE — ASAAS

### Por que Asaas?

| Critério | Asaas |
|----------|-------|
| **Boleto** | Gerência automaticamente, vencimento personalizado |
| **PIX** | QR Code instantâneo, confirmação em segundos |
| **Cartão** | Crédito, débito, parcelamento |
| **Recorrência** | Cobranças recorrentes para clientes fiéis |
| **API** | Integrção simples, boa documentação |
| **Taxas** | Competitivas para B2B |
| **Suporte** | Brasileiro, horário comercial |

### Fluxo de Pagamento

```
CHECKOUT → ESCOLHE FORMA → PAGA → CONFIRMA → PEDIDO LIBERADO
              │
              ├── Boleto → 1-2 dias úteis
              ├── PIX → Instantâneo
              └── Cartão → Aprovação imediata
```

### Integração Técnica
```javascript
// Exemplo simplificado
const pagamento = await asaas.payments.create({
  customer: clienteId,
  billingType: "PIX", // ou "BOLETO", "CREDIT_CARD"
  value: 1250.00,
  dueDate: "2026-08-10",
  description: "Pedido #ORD-ABC123",
  externalReference: orderId,
});
```

### Segurança no Pagamento
- **Tokenização** — Dados do cartão nunca ficam no servidor
- **PCI DSS** — Certificação de segurança
- **3D Secure** — Autenticação adicional para cartão
- **Antifraude** — Análise comportamental automática

## 10. SEGURANÇA

### Camadas de Segurança

```
┌─────────────────────────────────────┐
│  1. HTTPS (TLS 1.3)                │ ← Criptografia em trânsito
├─────────────────────────────────────┤
│  2. Autenticação (Supabase Auth)   │ ← Senhas hasheadas (bcrypt)
├─────────────────────────────────────┤
│  3. Autorização (RLS)              │ ← Controle por linha
├─────────────────────────────────────┤
│  4. Validação (Zod + Server)       │ ← Dados validados em 2 camadas
├─────────────────────────────────────┤
│  5. Rate Limiting                  │ ← Proteção contra brute force
├─────────────────────────────────────┤
│  6. CSP Headers                    │ ← Proteção contra XSS
└─────────────────────────────────────┘
```

### Medidas Implementadas

| Área | Medida |
|------|--------|
| **Senhas** | Bcrypt com salt, mínimo 8 caracteres |
| **Sessões** | Token JWT com expiração de 1h, refresh automático |
| **API** | Rate limiting (5 req/s por IP) |
| **Inputs** | Sanitização contra XSS e SQL injection |
| **Dados** | Criptografia em repouso (AES-256) |
| **Logs** | Auditoria de ações sensíveis |
| **Backup** | Diário automático, retenção 30 dias |

### Checklist de Segurança
- [x] HTTPS obrigatório
- [x] Senhas hasheadas
- [x] Validação de entrada
- [x] RLS no banco
- [x] Rate limiting
- [x] CSP headers
- [ ] WAF (Web Application Firewall) — fase 2
- [ ] Penetration testing — fase 2

## 11. LGPD — LEI GERAL DE PROTEÇÃO DE DADOS

### O que é LGPD?
Lei nº 13.709/2018 — Regulamenta o tratamento de dados pessoais no Brasil.

### Dados Coletados pelo E-commerce

| Dado | Finalidade | Base Legal | Retenção |
|------|-----------|------------|----------|
| **Nome** | Identificação | Execução de contrato | 5 anos |
| **Email** | Comunicação | Execução de contrato | 5 anos |
| **CPF/CNPJ** | Nota Fiscal | Obrigação legal | 5 anos |
| **Telefone** | Contato/entrega | Execução de contrato | 5 anos |
| **Endereço** | Entrega | Execução de contrato | 5 anos |
| **Dados de pagamento** | Processar compra | Execução de contrato | Conforme operadora |
| **IP/Acesso** | Segurança | Legítimo interesse | 1 ano |

### Direitos do Titular

```
┌─────────────────────────────────────┐
│  MEUS DIREITOS (LGPD)               │
│                                     │
│  ✓ Acessar meus dados               │
│  ✓ Corrigir dados incorretos        │
│  ✓ Solicitar exclusão               │
│  ✓ Revogar consentimento           │
│  ✓ Solicitar portabilidade          │
│  ✓ Não ser identificado             │
```

### Implementação Técnica
